## 🛠️ Setup and Installation

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor (VS Code, Sublime Text, etc.) - optional for editing
- Basic understanding of HTML/CSS/JavaScript - optional for customization

### Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/NusratBegum/portfolio-website.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd portfolio-website
   ```

3. **Open in browser**
   - Simply open `index.html` in your preferred web browser
   - Or use a local server (recommended):
   
   **Using Python:**
   ```bash
   # Python 3
   python -m http.server 8000
   # Then visit http://localhost:8000
   ```
   
   **Using Node.js (http-server):**
   ```bash
   npx http-server
   # Then visit http://localhost:8080
   ```
   
   **Using VS Code Live Server:**
   - Install the "Live Server" extension
   - Right-click on `index.html` and select "Open with Live Server"

## 📝 Customization Guide

### Updating Personal Information

1. **Profile Information**: Edit the content in `index.html`
   - Update name, tagline, and biography in the hero and about sections
   - Replace placeholder images with your own photos

2. **Contact Details**: Update phone number and email
   - Find and replace `+8801830363641` with your number
   - Update email addresses in the contact section

3. **Social Media Links**: Update social media URLs in the footer section
   - Twitter, Instagram, Pinterest, YouTube links

4. **Colors**: Modify the color scheme in `css/templatemo-first-portfolio-style.css`
   ```css
   :root {
     --primary-color: #535da1;
     --secondary-color: #14B789;
     /* Modify these variables */
   }
   ```

## 🌐 Deployment

### GitHub Pages

1. Go to your repository settings on GitHub
2. Navigate to "Pages" section
3. Select the branch (main/master) and root directory
4. Save and wait for deployment
5. Your site will be available at `https://[username].github.io/[repository-name]`

### Other Hosting Options

- **Netlify**: Drag and drop the project folder
- **Vercel**: Connect your GitHub repository
- **Firebase Hosting**: Use Firebase CLI to deploy
- **Traditional Hosting**: Upload files via FTP to your web server
